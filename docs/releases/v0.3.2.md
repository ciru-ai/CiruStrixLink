# CiruStrixLink 0.3.2 — superseded

Version 0.3.2 added host-specific workload detection that did not belong in a
general CiruStrixLink release. Version 0.3.3 removes that behavior while keeping
the paired Launch workflow and two-rank runtime reporting intact.

Users should skip 0.3.2 and install 0.3.3 or newer.
