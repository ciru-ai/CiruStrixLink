# iproute2

CiruStrixLink requires the `ip` command for interface inspection, route
assertions, and its temporary network backend.

Common package names:

```text
Ubuntu/Debian: iproute2
Fedora/RHEL:   iproute
Arch:          iproute2
NixOS:         pkgs.iproute2
```

After installation, verify:

```bash
ip -V
ciru-strixlink prerequisites
```
