# Linux requirement

CiruStrixLink configures Linux USB4NET and currently supports Linux on x86-64.
The setup and benchmark commands are not supported on Windows or macOS.

Check the running system with:

```bash
uname -srmo
```

Use the native operating system on both Strix Halo peers. Virtual machines and
containers generally do not own the host USB4 controller or persistent network
configuration and are not supported setup targets.
